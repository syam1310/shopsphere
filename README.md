# ShopSphere

ShopSphere is a scalable e-commerce platform built using Java,
Spring Boot and a microservices architecture.

## Project Goals

- Build a production-style backend
- Implement microservices architecture
- Implement JWT authentication
- Use PostgreSQL for persistent data
- Use Redis for caching
- Use Apache Kafka for event-driven communication
- Containerize services using Docker
- Provide REST APIs with OpenAPI/Swagger
- Implement automated tests

## Technology Stack

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Spring Security
- JWT
- Redis
- Apache Kafka
- Docker
- Maven
- JUnit
- Mockito
- OpenAPI/Swagger

- Product Service
